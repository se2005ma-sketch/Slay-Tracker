SLAY TRACKER — демонстрационный каркас

Запуск:
1. Распакуйте архив.
2. Откройте index.html в современном браузере.

Внутри:
- 14 номинаций, опубликованных на официальном сайте SLAY 2026.
- 2 дополнительных слота, поскольку они определяются отдельным голосованием.
- Пример списка SLAY KING из публикации от 16.11.2026.
- Локальная админ-консоль для изменения синтетических показателей и скорости прироста.
- Явные пометки DEMO / SIMULATED: показатели не являются официальными результатами.

Важно:
Это frontend-прототип. Данные сохраняются в оперативной памяти страницы и сбрасываются при перезагрузке.
Полные составы остальных номинаций не были доступны в извлечённой версии официального сайта; их нужно сверить и добавить вручную.
